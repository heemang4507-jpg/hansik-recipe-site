# 오늘의 한식 식탁

한식 레시피를 종류별로 살펴보고, 이름이나 재료로 검색할 수 있는 웹앱입니다. 레시피 카드를 누르면 재료와 만드는 순서가 나옵니다.

**내 레시피 추가** 버튼으로 나만의 레시피와 사진을 저장하고, 나중에 수정하거나 삭제할 수 있습니다. 내 레시피는 현재 사용 중인 브라우저에만 저장됩니다. 다른 기기에는 보이지 않으며 브라우저 데이터를 지우면 사라질 수 있습니다.

미리 보려면 이 폴더에서 `python -m http.server 8000`을 실행한 뒤 브라우저에서 `http://localhost:8000/`을 여세요.

GitHub Pages에서는 저장소의 루트(`/`)에서 배포하도록 설정하면 됩니다.
